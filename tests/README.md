# اختبارات تطبيق نسيم

بتفتح التطبيق في متصفح حقيقي وتجرّب كل ميزة زي المستخدم بالظبط، وتطلع ✓ أو ✗ لكل حاجة.

## التشغيل (مرة واحدة)

```bash
cd tests
npm install        # بينزّل متصفح للاختبار
npm test
```

## اختبار النسخة الاحتياطية مع السيرفر (اختياري)

شغّل السيرفر الأول، وبعدين:

```bash
NASEM_API=http://localhost:8000 npm test
```

## بيختبر إيه

| القسم | أمثلة |
|---|---|
| الفتح | التطبيق بيفتح من غير أخطاء، ومفيش حاجة مغطية الشاشة |
| الحسابات | شكك، دفعات، موردين، أرقام بالكلام ("بمية وخمسين")، ميعاد دفع |
| الجمعيات | المنظّم بيسجل الدفع، تذكير الجروب من غير أسامي |
| الصنايعي | الضمان، التقييم، مقارنة السعر |
| البحث والتقرير | البحث بالصوت، تقرير الشهر، صفحة فلوسي |
| الاعتمادية | بيانات بايظة ما بتوقعش التطبيق |
| القفل | رقم غلط/صح، الانتظار بعد 5 محاولات |
| النسخة الاحتياطية | الملف متشفر، كلمة سر غلط بترفض، الصح بيرجّع |

قبل أي رفع على GitHub: `npm test` لازم يطلع صفر ✗.
